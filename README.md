# RandomAccessFile

Práctica de Java desarrollada durante mi formación en Desarrollo de Aplicaciones Multiplataforma (DAM), centrada en el acceso aleatorio a ficheros.

## Descripción

El proyecto contiene siete ejercicios prácticos para trabajar con ficheros mediante la clase `RandomAccessFile` de Java.

A través de los ejercicios se practican la escritura y lectura de datos, el desplazamiento del puntero y el acceso directo a registros mediante posiciones concretas dentro de un fichero.

## Ejercicios realizados

- Ejercicio 1: Escritura y lectura de registros de empleados.
- Ejercicio 2: Escritura y lectura de números enteros.
- Ejercicio 3: Acceso directo a posiciones concretas mediante `seek()`.
- Ejercicio 4: Escritura y lectura de cadenas con `writeUTF()` y `readUTF()`.
- Ejercicio 5: Acceso aleatorio a registros de tamaño fijo.
- Ejercicio 6: Búsqueda y actualización de registros.
- Ejercicio 7: Búsqueda de registros mediante un fichero índice.

## Tecnologías y conceptos

- Java
- RandomAccessFile
- Lectura y escritura de ficheros
- Registros de tamaño fijo y variable
- Punteros y desplazamientos con `seek()`
- Gestión de excepciones (`IOException`)

## Estructura del proyecto

- `src/`: contiene los siete ejercicios Java y el archivo `conclusiones.txt`.
- `conclusiones.txt`: explicación de las diferencias entre registros de tamaño fijo y variable.
